## Мощность и изменения сигналов

Мощность рассчитывается по формуле `plot_pump_power_change.py`, но без сглаживания:

1. Совместить 30%-й сценарий с временной сеткой 0%-го линейной интерполяцией.
2. Рассчитать для каждого сценария
   \[
   P(t)=\frac{(p_{\mathrm{pump}}(t)-1)Q_{\mathrm{pump}}(t)}{600}
   \quad[\mathrm{kW}],
   \]
   где давление в bar, расход в L/min. В коде сохранён исходный порядок
   коэффициентов `/60000 * 1e5 / 1e3`.
3. К каждой мощности применить `clean_spikes(window=20)` на полной записи,
   до разделения по движениям.
4. Сформировать \(\Delta P(t)=P_{30}(t)-P_0(t)\).

Для каждого из трёх расходов отдельно:

\[
\Delta Q_j(t)=Q_{j,30}(t)-Q_{j,0}(t),\qquad
j\in\{\mathrm{Lift\_DV\_QP},\mathrm{Tilt\_DV\_QP},\mathrm{Pump\_Q}\}.
\]

Расходы сохраняют экспортированные знаки и не фильтруются дополнительно.
P-портовые расходы обычно отрицательны, Pump_Q обычно положителен. Поэтому
знак корреляции для P-порта нельзя читать как знак изменения положительного
расхода питания. Смена знака расхода меняет знак r и наклона, но не R².

## Корреляция и величина изменения

Внутри каждого движения определим временное среднее
\(\langle f\rangle=T^{-1}\mathcal I[f]\), где I — интеграл методом трапеций.
Для \(x=\Delta Q_j\), \(y=\Delta P\):

\[
r_j=\frac{\langle(x-\langle x\rangle)(y-\langle y\rangle)\rangle}
{\sqrt{\langle(x-\langle x\rangle)^2\rangle
\langle(y-\langle y\rangle)^2\rangle}},
\qquad R_j^2=100r_j^2\quad[\%].
\]

Наклон регрессии с константой:

\[
\beta_j=\frac{\langle(x-\langle x\rangle)(y-\langle y\rangle)\rangle}
{\langle(x-\langle x\rangle)^2\rangle}
\quad[\mathrm{kW}/(\mathrm{L/min})].
\]

Это корреляция **изменений**, а не уровней Q и P. Временные сдвиги не подбираются.
R² описывает долю вариации ряда изменения мощности, объясняемую отдельной линейной
моделью по изменению одного расхода. Это не доля энергии и не причинный процент
влияния; три R² нельзя складывать. Для постоянных рядов корреляция не определена
и сохраняется пустой ячейкой (NaN).

Дополнительно для мощности приведены средние P0/P30, относительное изменение
средней мощности и RMS разности в kW. Для каждого расхода:

\[
\delta\overline Q_j=100\frac{\langle Q_{j,30}\rangle-\langle Q_{j,0}\rangle}
{\langle Q_{j,0}\rangle},\qquad
\mathrm{RMS}_{\Delta Q,j}^{rel}=100
\sqrt{\frac{\langle(\Delta Q_j)^2\rangle}{\langle Q_{j,0}^2\rangle}}.
\]

Средние расходы обоих сценариев также записаны в L/min. Нулевые знаменатели
дают NaN. Для каждой группы из семи колонок используются префиксы
`lift_dv_qp_`, `tilt_dv_qp_`, `pump_q_`:
`mean_0_l_min`, `mean_30_l_min`, `mean_change_percent`, `delta_rms_percent`,
`pearson_r`, `r_squared_percent`, `slope_kw_per_l_min`.
